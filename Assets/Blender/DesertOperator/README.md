## PBR 파일 용도

BaseColor는 색상 텍스처, Normal은 탄젠트 공간 노멀, Roughness는 거칠기 데이터입니다. MetallicSmoothness 파일은 RGB에 금속성, 알파에 부드러움(1−Roughness)을 저장합니다. Unity용 외부 재질을 만들 때 노멀과 데이터 맵의 가져오기 설정을 구분해야 합니다. 재질 경로는 MaterialManifest.json을 기준으로 연결할 수 있습니다.
