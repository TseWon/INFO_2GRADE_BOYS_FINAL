# SoloScene2·4 연구소 내부 에셋 계획

## 공통 아트 방향

- 시대감: 냉전기 후반—현대 초기의 군사 생명공학 연구소
- 주조색: 아이보리 도장, 그래파이트 금속, 탈색된 안전 황색, 경고 적색
- 오염 순서: SoloScene2는 정돈된 지상 연구동, SoloScene3은 붕괴·임시 폐쇄, SoloScene4는 오염·격리 실패가 가장 심한 구역
- 게임플레이: 주요 이동 폭 1.4 m 이상, 문 앞 1.2 m, 퍼즐 앞 2 m에는 장애물을 놓지 않는다.

## SoloScene2 — 지상 연구동·접수·원형 실험실

이 구역은 첫 인상과 정상적이었던 연구소의 기능을 보여준다.

1. 우선 배치
   - 접수 카운터, 방문자 기록부, 출입증 트레이, 데스크 전화기
   - 원형 탁자 위 현미경, 보관 용기, 슬라이드 박스, 작은 데이터 로거
   - msy_B7Fp49TSYqmt2egwK3PaWYB5dfdEaeEn6J2o
   - 유리 뒤 실험 준비대와 금속 스토리지 트롤리
2. 세부 소품
   - 조직도, 보안 등급 표시, 실험실 번호판, 시계, 웨이트 스케일
   - 두꺼운 전원 케이블과 바닥 케이블 커버
3. 피해야 할 것
   - 혈흔과 부패 표현을 과도하게 넣지 않는다. 이 구역은 뒤의 공포를 대비시키는 정돈된 구역이다.

## SoloScene3 — 승강기·감옥·붕괴된 연구 통로

이 구역은 사고 이후 긴급 폐쇄와 구조 실패를 보여준다.

1. 우선 배치
   - 승강기 유압 제어반, 수동 브레이크, 절단된 케이블 지지대
   - 이동식 격리 펜스, 바리케이드, 잠금 장치, 증거품 표식 태그
   - 파손된 환기 덕트, 누수 배관, 고인 물, 임시 배수 펌프
   - 접이식 들것, 응급 구조 가방, 피묻은 붕대, 부상자 이동 슬링
2. 환경 스토리텔링
   - 모든 잔해는 탈출 방향과 어긋나지 않게 길가에 몰아 놓는다.
   - 이끌림 자국, 긋힌 금속판, 부러진 보안 패널로 모델 N의 이동 경로를 암시한다.
   - 그래피티 대신 급하게 쓴 격리 번호, 시간, 피험체 코드를 사용한다.

## SoloScene4 — B1/B2 심부 연구·격리·퍼즐 구역

이 구역은 PROJECT NULL의 실체와 실험 실패를 보여주는 핵심 공간이다.

1. 핵심 에셋
   - 대형 시편 보관 탱크 1–2종: 깨진 유리, 액체 레벨 표시, 생명 유지 호스
   - 실험대 모듈: 고정 클램프, 주사 펌프, 심전도 모니터, 샘플 서랍
   - 관찰실 제어 콘솔: CRT 모니터, 토글 스위치, 녹음기, 비상 차단 키
   - 고위험 폐기물 용기, 샤프 버킷, 오염 방지 트레이, 파손된 방호복
   - 천장 케이블 트레이, 배관 밸브, 압력계, 응결수 호스
2. 퍼즐 구역 배치 규칙
   - 성조기 슬라이딩, 디지털 표시기, 무전기의 시야선을 소품으로 가리지 않는다.
   - 퍼즐 주변에는 답을 직접 보여주는 소품 대신 연구 일지, 파손된 백업 모니터, 절반짜리 안전 표식을 배치한다.
   - 퍼즐 완료 후 열리는 셔터 뒤에는 이전 구역과 재질이 다른 격리 복도를 노출해 보상감을 준다.
3. 공포 연출
   - 모델 N이 지나간 벽과 바닥에만 유기질 피막·뿌리·신경 같은 데칼을 집중시킨다.
   - 배경 소음을 생성할 수 있는 환기팬, 느린 주사 펌프, 불안정한 형광등을 시각적으로 배치한다.

## 제작 우선순위

### P0 — 연출에 직접 필요

1. 모델 N 텍스처 완성본, 리토폴로지, 리깅 대비본
2. 시편 보관 탱크 세트
3. 관찰실 제어 콘솔
4. 실험대·클램프·주사 펌프 세트
5. 구조용 바리케이드·이동식 격리 펜스

### P1 — 공간 설득력 강화

1. 현미경·슬라이드·보관 용기 세트
2. 안전 샤워·응급 처치함·방호복 보관함
3. 배관·밸브·압력계·케이블 트레이 모듈
4. 폐기물 통·샤프 버킷·오염 트레이

### P2 — 스토리텔링 소품

1. 보안 출입증, 실험 태그, 증거 번호표
2. 클립보드, 녹음 테이프, 필름 카트리지
3. 방문자 기록부, 데스크 전화기, 타자기

## 재사용 및 성능

- 이미 있는 Research desk, steel storage cabinet, oak/steel table, walnut round table은 새로 제작하지 않고 재사용한다.
- 배관, 밸브, 케이블 트레이, 형광등은 반복 배치용 모듈로 제작한다.
- 작은 소품은 1–2개의 텍스처 아틀라스를 공유한다.
- 모델 N은 원본 폴리곤을 보존하고 Unity용 LOD0/LOD1/임포스터를 별도로 제작한다.
