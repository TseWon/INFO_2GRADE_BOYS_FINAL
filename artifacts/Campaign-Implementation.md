# 연쇄살인마의 집 — 멀티 캠페인

작업일: 2026-11-07 (한국 시간)

## 실행

- Unity에서 `Assets/Scene/MultiScene1.unity`를 열고 Play.
- 같은 빌드를 실행한 두 컴퓨터에서 A는 HOST, B는 호스트 IPv4를 입력하고 JOIN.
- 두 사람이 접속하면 호스트가 SPACE / START. 시작 전 화면에서 목표와 조작법을 확인한다.
- 마우스로 시점, E 또는 왼쪽 클릭으로 조작. 의자에서 풀린 뒤 WASD 이동, Shift 달리기.
- 협동 스위치와 발판은 **E 유지**. Esc로 커서를 해제하면 마이크 설정을 볼 수 있다.
- R은 호스트가 전체 라운드를 다시 시작한다. 연결 해제 시 둘 다 로비로 돌아간다.

## 기존 기능 유지

전기의자 모델과 구속장치, 매 라운드 달라지는 색상/기호 퍼즐, A의 흑백 시야, B 전용 안내판, 구속 해제 연출, LAN 역할 고정, 상대 아바타, 마이크 선택/음소거, 의자 탈출 전 단방향 및 탈출 후 양방향 음성 채팅을 유지했다. 싱글 씬은 수정하지 않았다.

## 챕터 1 — 전기의자

기존의 B가 힌트를 전달하고 A가 조작하는 구성을 유지한다. 색상 순서를 맞춘 뒤 3개의 기호 다이얼을 맞추고 레버를 당긴다.

- 현재 씬은 제한 시간 120초, 체력 3, 오답마다 두 사람 모두 -1 HP.
- 3회 오답 또는 제한 시간 초과로 실패한다. 오답 후 3초간 재입력을 제한한다.
- `MultiEscapeGame.damageOnMistake`를 끄면 기존의 주기적 전기 충격 규칙도 그대로 사용할 수 있다.
- 성공하면 흑백/음성 제한이 해제되고, 기존 출입문을 지나 증거실로 이동한다.

## 챕터 2 — 증거실

의자 탈출 시점부터 180초. 조명이 비추는 3개의 증거를 E로 확인하면 공동 수첩에 기록된다. 심장 → 눈 → 손 순서로 문 옆 숫자 다이얼을 맞춘다. 암호는 매 라운드 새로 생성된다. 세 증거를 모두 확인하고 두 사람이 문 앞에 모여 ENTER를 사용하면 추격전이 시작된다.

- 남은 60초: 타이머 흔들림, 점점 빨라지는 발소리와 숨소리.
- 남은 48~45초: 숨소리/배경음을 멈추는 정적.
- 남은 45~41초: 카메라 앞에 초당 3,200개의 벌레 파티클 방출, 최대 4,000개 풀, 윙윙거림과 흔들림. 이동/장치 조작 잠시 제한.
- 남은 41초: 탁자 충돌음과 카메라 충격/붉은 화면, 두 사람 모두 한 번만 -1 HP. 남은 체력이 1이었다면 사망한다.
- 시간 초과 시 실패. 공포 연출이 발생하기 전에 암호를 풀면 바로 다음 챕터로 갈 수 있다.

## 챕터 3 — 추격전

100초 제한. 8초의 출발 여유 후 전기톱 살인마가 지정 경로를 따라 추격한다. 노란 바닥 유도선을 따라 엇갈린 벽을 지나야 한다. 전기톱의 위치 음향, 사이렌, 붉은 경광등, 금속 발소리를 적용했다.

1. A/B 전용 스위치에서 두 사람이 E를 동시에 2초 유지하면 철문이 열린다. 한 명만 누르거나 놓으면 진행이 끊긴다.
2. 담장에서 한 사람은 낮은 발판을 바라보고 E를 유지한다. 다른 사람은 담장 조작부에서 E를 눌러 넘어간다.
3. 먼저 넘어간 사람이 뒤돌아 밧줄 조작부에 E를 눌러 밧줄을 내린다. 남은 사람은 담장 조작부에 E를 눌러 넘어간다.
4. 두 사람이 마지막 EXIT에 각각 E를 눌러야 성공한다. 한 명이 붙잡히거나 시간이 끝나면 팀 전체가 실패한다.

달리기에는 회복되는 스태미나가 있다. 맵은 실제 Collider가 있는 추가 공간으로 씬과 기존 프리팹에 저장했다. 기존 의자 방의 막힌 복도 끝 벽만 비활성화해 연결했다.

### 후속 보완

- 담장을 넘을 때 1.4초 동안 상승 → 벽 위 이동 → 착지 순서로 실제 캐릭터 위치가 움직인다. 등반 중에는 이동과 장치 조작을 막고, 착지 전에 밧줄을 내리거나 탈출 판정을 받지 못하게 했다.
- 등반 구간의 천장을 높여 몸과 카메라가 천장에 겹치지 않게 했다. 너무 멀리서 담장을 사용하면 가까이 오라는 안내를 표시한다.
- 스태미나가 소진되면 30% 회복까지 숨을 고른다. Shift를 계속 눌러도 낮은 스태미나에서 걷기와 달리기가 매 프레임 반복되지 않는다.
- 살인마의 다리·몸통·머리에 이동 거리에 맞춘 절차적 보행 동작을 추가했다.
- B가 잘못된 암호를 확인하거나 협동 조건을 충족하지 못하면, 호스트가 판정한 이유를 B의 화면에도 전달한다.
- LAN 프로토콜은 5번이다. 이전 빌드와 섞지 말고 양쪽 모두 최신 빌드를 사용한다.

## 구현 및 교체 지점

- `MultiEscapeCampaignRules`: 시간, 체력, 증거, 협동, 승패의 독립 규칙.
- `MultiEscapeCampaign`: 씬 참조, 거리/가림 검사, 호스트 판정, 한국어 HUD, 이동 경로.
- `MultiEscapeAtmosphere`: 절차적으로 합성한 임시 사운드, 벌레 파티클, 화면 충격.
- `MultiEscapeLanSession`: 기존 스냅샷에 캠페인 상태를 추가하고 B의 조작 요청을 호스트에서 처리. 라운드 번호로 이전 라운드 요청을 거부한다. 프로토콜 버전이 바뀌었으므로 양쪽 모두 새 빌드를 사용해야 한다.
- `MultiEscapePrototype/08_Campaign`: 추가된 증거실/추격전 오브젝트와 모든 연결. Inspector에서 위치와 참조를 조정할 수 있다.
- `artifacts/BuildEscapeCampaign.cs`, `PolishEscapeCampaign.cs`, `PolishEscapeClimbing.cs`: 제작에 사용한 에디터 스크립트. 이미 설치된 씬에서 초기 빌더를 중복 실행하지 않는다.

새 살인마와 추가 환경은 교체 가능한 기본 메시 기반이며, 사운드는 외부 저작물을 사용하지 않은 합성 효과음이다. 실제 걷기/달리기 애니메이션이 있는 최종 캐릭터나 녹음된 전기톱/호흡 음원을 적용하면 표현을 더 높일 수 있다. 추적 AI는 이 맵에 맞춘 경유점 방식이며 임의의 맵 변경 후에는 경로도 함께 조정해야 한다.

## 검증

- 순수 캠페인 검사 38개 + 기존 규칙/스냅샷/GPU 흑백 검사 43개 통과.
- 스태미나 소진/회복과 등반 경로 41지점의 캡슐 충돌 검사를 통과했다.
- 실제 Play Mode에서 프레임 진행 확인.
- 이번 실제 씬 검사 69개 통과: Collider 레이캐스트, 증거/암호, 추격 경로 통과 여부, 실제 시간의 동시 스위치, 동료 올리기/밧줄/공동 엔딩 검사 통과.
- 독립 프로세스 LAN 검사 48개 통과: 에디터 호스트 + Windows Development Player 클라이언트, 127.0.0.1. 오답 피해, 챕터 전환, B의 증거 입력, 공포 연출 피해, 두 사람 동시 스위치, 양쪽의 등반 시작·이동·착지 및 밧줄 동기화, B 화면의 거부 사유 안내, 공동 엔딩, 재시작, 연결 해제를 확인했다.
- Windows x64 Development 빌드 성공: `output/CampaignQA/Escape.exe`. 실행 파일만 복사하지 말고 해당 폴더 전체를 함께 사용한다. 검증용 빌드이며 출시용 빌드는 별도로 Development 옵션을 해제한다.
- 최종 Windows 빌드: Succeeded, 오류 0건, 경고 486건. 기존 Unity AI Inference 패키지의 Sentis/ConvGeneric 셰이더 경고 485건과 Player에서 Pipeline 원격 자동화가 비활성화되어 있다는 안내 1건이다. 빌드 및 LAN 실행 검증은 통과했다.
- 살인마와 실제 플레이어 Collider가 가까워졌을 때 팀 패배로 전환되는 동작, 엔딩의 재도전 화면도 확인했다.
- 벌레 파티클과 한국어 화면을 실제 Game View 캡처로 확인했다. 배치 실행한 검증 클라이언트에서는 마이크 출력 장치 초기화 오류가 발생해 실제 녹음 품질은 확인하지 않았다. 음성 송수신 허용 상태는 두 프로세스에서 확인했다.

두 대의 물리적인 PC 사이의 Wi-Fi, 공유기와 방화벽, 실제 헤드셋 마이크 녹음 품질은 이 환경의 자동 검증 범위에 포함되지 않는다.
